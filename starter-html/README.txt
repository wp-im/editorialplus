Tiny Editorial Text Only starter HTML snippets

Copy snippets from this folder into a WordPress page that uses the "Editorial Canvas" template, preferably in the Classic Editor Text/HTML tab.

Recommended workflow:
1. Create a new page.
2. Select the "Editorial Canvas" template.
3. Open the Classic Editor Text tab or the Code Editor.
4. Paste one or more snippets.
5. Replace text, links, and placeholder blocks.
6. Keep the class names unless you want to write custom CSS.

Links that point to "#" are placeholders and should be replaced after pasting.

The snippets do not require ACF, a page builder, or a custom block plugin.
